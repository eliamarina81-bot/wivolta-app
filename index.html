Registar contrato para acompanhamento

Preencha uma vez para solicitar o acompanhamento. A primeira revisão fica agendada para 90 dias após o registo; as revisões seguintes são trimestrais. Os dados incompletos ficam sinalizados para confirmação e nenhuma mudança de fornecedor é executada automaticamente.

No AutoSwitch, a Wivolta só poderá executar mudanças depois de existir uma procuração autónoma, juridicamente validada e aceite pelo titular e pelos comercializadores. Este pedido ainda não concede poderes para mudar contratos.
